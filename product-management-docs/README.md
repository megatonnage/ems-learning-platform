# 📁 Product Management Docs

## How to Upload to Google Drive

### Step 1: Create a Folder in Google Drive
1. Go to https://drive.google.com
2. Click "New" → "Folder"
3. Name it: "Product Management"
4. Open the folder

### Step 2: Upload These Files
You can upload in two ways:

**Option A: Drag and Drop**
- Select all .md files in this folder
- Drag them to your Google Drive "Product Management" folder
- They'll upload as Google Docs automatically

**Option B: Upload Button**
1. In Google Drive, click "New" → "File upload"
2. Select all the .md files
3. They'll convert to Google Docs format

### Step 3: Organize (Optional)
Create subfolders if you want:
- /Strategy (Product Principles, Positioning, Core Value)
- /Process (How We Build, How We Prioritize)
- /Planning (Research Bets, Templates)

### Step 4: Share (Optional)
Share the folder with team members:
1. Right-click "Product Management" folder
2. Click "Share"
3. Add people or get shareable link
